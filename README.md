# 林晓夏 · 旅行博主个人主页

一个面向中文旅行博主的响应式个人主页（虚构角色「林晓夏」），使用 Vite + 原生 HTML/CSS/JS 构建。

## 功能亮点

- Hero 首屏、关于我、精选目的地故事卡片、光影相册、联系 / 关注 CTA
- 移动优先布局、CSS 变量、沙色 / 海洋 / 日落暖色旅行配色
- 语义化 HTML、键盘焦点样式、良好对比度
- Unsplash CDN 图片（含 alt 文案）

## 本地运行

1. npm install
2. npm run dev

开发服务器启动后，打开终端提示的本地地址（通常是 http://localhost:5173）。

## 构建

1. npm run build — 产物输出到 dist/
2. npm run preview — 预览构建结果

## 技术栈

- Vite 5
- 原生 HTML / CSS / JavaScript（无框架）

## 部署

推送到 `main` 分支会通过 GitHub Actions 自动构建并部署到 GitHub Pages：https://hubboys.github.io/grok-bot-demo/
